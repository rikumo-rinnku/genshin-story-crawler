# 圣遗物模块维护笔记

> 对应 `src/modules/artifact.py`，频道配置键为 `artifact`。

模块解析圣遗物套装的目录、筛选标签、详情与背景描述，并发布 `artifact:<entry_id>` 稳定语料。一个条目对应一份正文；标题、套装名称和稀有度只作为文本内容或元数据。

维护时重点核对详情组件中是否仍含故事/描述字段，避免只抓到数值属性。所有正文必须使用 `save_document()`；不要恢复旧的按中文名命名方式。解析 `ext` 失败应记录警告但不应使整个目录中断。

对官方页面改版的处理顺序：保存异常 ID → 查看接口 JSON → 补充解析 → 定向更新 → Manifest 严格校验。
