# 角色逸闻模块维护笔记

> 对应 `src/modules/character_anecdote.py`。这是角色的分段扩展语料，不是普通角色正文。

## 身份与输出

模块通过频道键 `anecdote` 获取角色逸闻页，并以角色 ID 与逸闻章节 ID 共同标识：`character_anecdote:<character_id>:<section_id>`。正文文件使用 `<character_id>__<section_id>.txt`；不得再按“角色名_章节名”写文件。

## 解析要求

逸闻内容常包含富文本和交互对话。`parse_interactive_dialogue()` 需保留选项与台词，并兼容新版 `list` 包装和旧版顶层对话树。标题用于 Manifest 元数据和日志，不能参与主键判断。

## 维护检查

新增逸闻时确认它写入 `character_anecdote` 模块，而不是旧目录名造成重复。缺少某段时按角色/章节 ID 检查接口 JSON，补写后运行 Manifest 校验；RAG 以独立分段 `doc_id` 入库。
