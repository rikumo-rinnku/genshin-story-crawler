## `src/core` 核心模块实现详解

本文档记录了《原神》剧情爬虫项目中 `src/core` 目录下四个基础模块的设计思路、实现细节和关键代码。这些模块为上层爬虫提供了统一的请求、解析、存储和配置管理能力。

---

### 1. `client.py` —— 统一 HTTP 请求客户端

**功能**：封装 HTTP 请求，提供自动重试、超时控制、默认请求头等特性，避免在每个爬虫模块中重复编写请求逻辑。

**设计思路**：
- 使用 `requests` 库发送同步请求。
- 利用 `tenacity` 库实现重试机制（默认重试 3 次，指数退避等待）。
- 设置合理的超时（30 秒）和默认 User-Agent，模拟浏览器行为。
- 仅实现 `get` 方法（当前够用），预留 `post` 接口。

**代码实现** (`src/core/client.py`)：
```python
import requests
from tenacity import retry, stop_after_attempt, wait_random_exponential

@retry(stop=stop_after_attempt(3), wait=wait_random_exponential(multiplier=1, max=10))
def get(url, headers=None, params=None, timeout=30):
    if headers is None:
        headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"}
    resp = requests.get(url, headers=headers, params=params, timeout=timeout)
    resp.raise_for_status()
    return resp

def post(url, data=None, headers=None, json=None):
    # 暂未使用，保留接口
    pass
```

**注意事项**：
- 重试机制仅对网络错误或 5xx 状态码生效，4xx 错误不会重试（由 `raise_for_status()` 抛出异常）。
- 可根据目标站点的反爬策略调整重试参数和头信息。

### 2. `parser.py` —— HTML 文本清洗工具

**功能**：将 HTML 格式的剧情内容转换为纯文本，去除标签、多余空白，保留段落结构。

**设计思路**：
- 使用 `BeautifulSoup` 解析 HTML，`lxml` 作为解析器（速度快）。
- 调用 `get_text()` 提取纯文本，用换行符分隔块级元素。
- 使用正则表达式将连续的多个换行符压缩为至多两个，保持可读性。

**代码实现** (`src/core/parser.py`)：
```python
import re
from bs4 import BeautifulSoup

def clean_html_to_text(html: str) -> str:
    soup = BeautifulSoup(html, 'lxml')
    text = soup.get_text(separator='\n', strip=True)
    text = re.sub(r'\n\s*\n', '\n\n', text)
    return text.strip()
```

**注意事项**：
- 如果将来遇到非 HTML 的文本来源（如纯 JSON 字段），可以增加适配函数。
- 清洗后的文本适合直接存入 `.txt` 文件供 RAG 使用。

### 3. `storage.py` —— 增量爬取状态与文件存储

**功能**：
- 管理已爬取记录 (`crawled.json`)，支持按模块和条目 ID 检查、标记。
- 提供统一的文本保存接口，按模块和 ID 组织目录结构。

**设计思路**：
- 使用 JSON 文件存储已爬取的条目 ID 列表，结构为 `{ "module_name": [id1, id2, ...] }`。
- 每次检查时加载整个 JSON 到内存（条目数最多几千，性能可接受）。
- 保存文本时自动创建 `data/cleaned/{module}/{id}.txt`，并在文件头部可选地添加名称注释。

**代码实现** (`src/core/storage.py`)：
```python
import json
import os

CRAWLED_FILE = "data/crawled.json"

def load_crawled():
    if os.path.exists(CRAWLED_FILE):
        with open(CRAWLED_FILE, 'r', encoding='utf-8') as f:
            content = f.read().strip()
            if not content:
                return {}
            return json.loads(content)
    return {}

def save_crawled(data):
    with open(CRAWLED_FILE, 'w', encoding='utf-8') as f:
        json.dump(data, f, indent=2, ensure_ascii=False)

def is_crawled(module, entry_id):
    data = load_crawled()
    return entry_id in data.get(module, [])

def mark_crawled(module, entry_id):
    data = load_crawled()
    data.setdefault(module, [])
    if entry_id not in data[module]:
        data[module].append(entry_id)
        save_crawled(data)

def save_text(content, module, entry_id, name=None):
    dir_path = os.path.join("data", "cleaned", module)
    os.makedirs(dir_path, exist_ok=True)
    file_path = os.path.join(dir_path, f"{entry_id}.txt")
    if name:
        full_content = f"# {name}\n\n{content}"
    else:
        full_content = content
    with open(file_path, 'w', encoding='utf-8') as f:
        f.write(full_content)
    print(f"保存文本: {file_path}")
```

**注意事项**：
- `crawled.json` 文件初始内容应为 `{}`，若为空文件会导致 `json.loads` 失败，故做了空内容处理。
- 使用 ID 而非名称作为文件名，避免特殊字符和重名问题。

### 4. `config_loader.py` —— 频道配置管理

**功能**：读取 `config/channels.json` 文件，提供按模块名获取频道 ID 的接口。

**设计思路**：
- 将不同模块（角色、敌人、武器等）的频道 ID 集中配置在 JSON 文件中，便于维护和扩展。
- 在爬虫模块中通过 `get_channel_id("character")` 获取，避免硬编码数字。

**代码实现** (`src/core/config_loader.py`)：
```python
import json
import os

CONFIG_PATH = os.path.join("config", "channels.json")

def load_channel_config():
    if not os.path.exists(CONFIG_PATH):
        raise FileNotFoundError(f"配置文件不存在: {CONFIG_PATH}")
    with open(CONFIG_PATH, 'r', encoding='utf-8') as f:
        return json.load(f)

def get_channel_id(module_name: str) -> int:
    config = load_channel_config()
    return config[module_name]["channel_id"]
```

**配置文件示例** (`config/channels.json`)：
```json
{
    "character": {
        "channel_id": 25,
        "name": "角色",
        "enabled": true
    },
    "enemy": {
        "channel_id": 6,
        "name": "敌人",
        "enabled": true
    }
}
```

**注意事项**：
- 未来扩展新模块只需在 JSON 中添加条目，无需修改代码逻辑。
- 可在配置中加入 `enabled` 字段，配合调度器选择性运行模块。

## 📌 总结

`src/core` 模块为爬虫项目提供了以下基础能力：

| 模块               | 职责                | 关键依赖                 |
| ------------------ | ------------------- | ------------------------ |
| `client.py`        | 可靠的 HTTP 请求    | `requests`, `tenacity`   |
| `parser.py`        | HTML → 纯文本转换   | `beautifulsoup4`, `lxml` |
| `storage.py`       | 增量记录 + 文件保存 | 标准库 `json`, `os`      |
| `config_loader.py` | 读取频道配置        | 标准库 `json`, `os`      |

这些模块的设计遵循**单一职责**和**可复用**原则，使上层爬虫模块（如 `character.py`）只需关注业务逻辑（如何解析列表和详情），而无需关心网络重试、文件存储等底层细节。
