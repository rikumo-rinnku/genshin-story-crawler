# 组织模块维护笔记

> 对应 `src/modules/organization.py`，频道配置键为 `organization`。

组织模块提取组织的资料、简介和可折叠富文本，并发布 `organization:<entry_id>`。详情中可能含引用、折叠面板或空面板；解析应保留有效叙事文本，跳过确认为空的组件。

官方接口曾出现 HTTP 成功但正文 JSON 损坏的瞬时响应，因此请求必须复用 `src.core.client.get()`，不要绕过核心客户端直接请求。一次目录获取失败不代表目录为空；先看模块报告并重试。

成功写入稳定 ID 正文后再标记已抓取，最后由 Manifest 决定是否进入 RAG。
