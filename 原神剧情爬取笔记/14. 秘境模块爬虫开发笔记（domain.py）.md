# 秘境模块维护笔记

> 对应 `src/modules/domain.py`，频道配置键为 `domain`。

模块提取秘境类型、地区、开放/奖励说明和详情文本，发布 `domain:<entry_id>`。目录项和详情项都可能因官方数据暂缺而返回无正文；此时应记录失败，不写入空的 `ready` 文档。

正常流程是：读取目录 ID → 跳过已抓取 → 请求详情 → 清洗概要 → `save_document()` → `mark_crawled()`。既有 ID 未必永久不变，版本更新后可按 ID 定向复核。

输出质量由 Manifest 校验决定；仅有文本文件或 crawled 标记不足以证明可入库。
