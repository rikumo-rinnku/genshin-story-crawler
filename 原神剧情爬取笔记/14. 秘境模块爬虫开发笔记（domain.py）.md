## 秘境模块爬虫开发笔记（`domain.py`）

> 本文档记录了《原神》观测枢秘境爬虫模块的设计思路、API 分析、数据结构解析和实现细节，适用于项目维护和后续扩展。


### 一、模块概述

**模块名称**：`domain.py`  
**功能**：从米哈游观测枢 Wiki 爬取所有秘境的简要信息及剧情简述（仅保留文本故事），包括：
- 秘境名称、秘境类型（武器突破素材/圣遗物/天赋培养素材/角色培养素材/角色经验素材/摩拉/一次性秘境）
- 秘境消耗（原粹树脂*20/*60/无消耗）
- 是否可联机（是/否）
- 是否为任务本（是/否）
- 推荐元素（火/水/风/雷/冰/岩/草）
- 列表页简介（`summary` 字段）
- 详情页“简述”模块的剧情叙述文本

**输出**：每个秘境保存为一个 `.txt` 文本文件，存放在 `data/cleaned/domain/` 目录下。

**增量策略**：
- 使用 `crawled.json` 记录已爬取的秘境 ID。
- 每次运行先检查 ID 是否已记录，若已记录则跳过，避免重复请求。
- 若官方更新了内容，需手动从 `crawled.json` 中删除对应 ID，重新运行以更新。

### 三、API 分析

#### 3.1 秘境列表 API

- **URL**: `https://act-api-takumi-static.mihoyo.com/common/blackboard/ys_obc/v1/home/content/list`
- **参数**: `app_sn=ys_obc`, `channel_id=54`（秘境频道）
- **响应结构**:
  ```
  data.data.list[0] → name: "秘境"
      └── list[] → 每个秘境条目
          ├── content_id: 秘境 ID
          ├── title: 秘境名称
          ├── summary: 简介（含掉落物、位置等信息）
          └── ext: 包含分类标签的 JSON 字符串
  ```

#### 3.2 秘境详情 API

- **URL**: `https://act-api-takumi-static.mihoyo.com/hoyowiki/genshin/wapi/entry_page`
- **参数**: `app_sn=ys_obc`, `entry_page_id={秘境ID}`, `lang=zh-cn`
- **核心模块**（仅提取“简述”）:
  - `modules[].name == "简述"`：包含剧情叙述文本。
  - 组件类型：`multi_table`，每个 `tab` 包含一段叙述文本。
  - 其他模块（`role_base_info`、`map_desc`、`秘境详情`）均跳过。

**设计决策**：仅提取“简述”模块中的纯文本叙述，忽略所有数值类内容（掉落列表、敌人列表、地脉异常机制说明等），以保持输出轻量且聚焦于剧情故事。


### 四、数据结构与解析逻辑

#### 4.1 列表 `ext` 字段解析

`ext` 是一个 JSON 字符串，包含秘境的分类筛选标签：

```json
{
  "c_54": {
    "filter": {
      "text": "[\"秘境类型/圣遗物\", \"秘境消耗/原粹树脂*20\", \"是否可联机/是\", \"是否为任务本/否\"]"
    }
  }
}
```

解析后得到：
- `domain_type`: "圣遗物"
- `cost`: "原粹树脂*20"
- `can_coop`: "是"
- `is_task`: "否"
- `recommended_elements`: []（可能包含多个推荐元素）

#### 4.2 详情页“简述”模块解析

“简述”模块的数据结构：

```json
{
  "component_id": "multi_table",
  "data": {
    "tables": [
      {
        "tab_name": "万有涅槃缚境",
        "row": [[ "<p>昔日维系记忆的世界树...</p>" ]]
      },
      {
        "tab_name": "追忆：阴妄一念",
        "row": [[ "<p>异端之人将维系世界记忆...</p>" ]]
      }
    ]
  }
}
```

**提取逻辑**：
1. 遍历 `modules`，仅处理 `module_name == "简述"` 的模块。
2. 遍历 `tables`，取每个 `tab` 的 `row[0][0]`（第一行第一列）的 HTML 文本。
3. 使用 `clean_html_to_text` 清洗 HTML。
4. 使用 `tab_name` 作为小标题，拼接所有段落。

#### 4.3 跳过模块

| 模块名   | 组件类型         | 跳过原因                                                     |
| :------- | :--------------- | :----------------------------------------------------------- |
| 秘境信息 | `role_base_info` | 仅包含类型、消耗、联机等属性，已在列表数据中获取             |
| 秘境位置 | `map_desc`       | 纯图片，无文本内容                                           |
| 秘境详情 | `multi_table`    | 包含掉落列表、敌人列表、地脉异常机制说明，对剧情向 RAG 价值低 |


### 五、输出格式

每个秘境保存为一个 `.txt` 文件，文件名使用秘境名称（非法字符替换为 `_`）。

【简述】

### 六、核心函数说明

| 函数                                            | 职责                                                         |
| :---------------------------------------------- | :----------------------------------------------------------- |
| `get_domain_list()`                             | 获取所有秘境的 ID、名称、简介和分类标签（秘境类型/消耗/联机/任务本/推荐元素）。 |
| `parse_domain_ext(ext_str)`                     | 解析 `ext.filter.text` 中的 JSON 数组，提取五个分类维度。    |
| `parse_domain_detail(page_data)`                | 遍历 `modules`，仅提取“简述”模块中的叙述文本，返回拼接后的纯文本。 |
| `generate_domain_content(domain_info, summary)` | 将列表数据与简述文本格式化为纯文本内容。                     |
| `process_domain(domain, output_dir)`            | 请求详情 API，提取简述并保存单个秘境。                       |
| `run()`                                         | 主流程，控制爬取范围和增量逻辑。                             |

### 十、注意事项

1. **仅提取简述模块**：秘境详情页中只有“简述”模块包含可读的剧情叙述文本，其他模块（秘境信息、秘境位置、秘境详情）均为属性或数值类内容，已全部跳过。
2. **无简述则跳过**：若某个秘境没有“简述”模块（如大部分圣遗物本、武器本），该秘境将被跳过，不生成文件。
3. **多段落拼接**：简述模块可能包含多个 `tab`（如“万有涅槃缚境”和“追忆：阴妄一念”），每个 `tab` 的文本会被独立提取并拼接，用空行分隔。
4. **列表数据完整性**：即使秘境没有简述，列表数据也会被记录，但不会生成文件。未来如果需要，可通过修改 `process_domain` 的逻辑，为无简述的秘境生成仅含元信息的文件。
5. **文件名清洗**：秘境名称可能包含特殊字符（如 `「」`、`·`），使用 `safe_filename` 替换为下划线。
6. **空内容过滤**：若秘境详情页无任何可提取文本，该秘境将被跳过，不生成文件。

### 十二、后续优化方向

1. **一次性秘境补充**：部分“一次性秘境”（试炼秘境）可能包含更多剧情文本，但当前数据中“简述”模块已覆盖了主要叙事内容。未来可考虑单独为这些秘境补充更多信息。
2. **支持增量更新**：通过内容哈希检测变更，避免手动删除 ID。
3. **多线程并发**：使用线程池加速爬取（需控制并发数避免风控）。
4. **命令行参数**：支持通过 `argparse` 指定 `test_limit` 或特定的秘境 ID 列表。
