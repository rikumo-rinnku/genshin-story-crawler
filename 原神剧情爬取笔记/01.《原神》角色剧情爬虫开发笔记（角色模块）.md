# 角色模块维护笔记

> 对应 `src/modules/character.py`，频道配置键为 `character`。

## 职责

抓取角色图鉴页中的基础资料、故事、语音与登场相关内容，并以 `character:<entry_id>` 发布一份角色正文。旅行者使用模块内专门的补充逻辑，不能因常规列表字段差异而直接判定缺失。

## 统一约定

- 列表 ID 来自 `config/channels.json` 的角色频道；详情使用官方 `entry_page` 接口。
- 写入必须调用 `save_document(story, "character", character_id, character_name)`；正文路径为稳定 ID 文件。
- 成功写入后才调用 `mark_crawled()`；标题仅用于显示和增量状态映射。

## 复核重点

检查角色正文是否包含实际故事内容而非仅基础属性。官方组件名称、富文本结构可能调整；应在详情 JSON 中定位组件后扩展解析函数。更新后重建并校验 Manifest，不能以中文标题文件作为结果依据。
