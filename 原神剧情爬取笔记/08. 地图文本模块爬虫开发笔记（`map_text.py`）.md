# 地图文本模块维护笔记

> 对应 `src/modules/map_text.py`，频道配置键为 `map_text`。本模块已恢复并纳入 `run.py` 的统一调度。

## 输出与内容

每条地图文本发布为 `map_text:<entry_id>`，正文包含名称、地区、分类、活动限定、简介、交互文本和相关任务。只有实际含 `【内容】` 或 `【相关任务】` 的条目才写入，避免空语料。

## 对话兼容

官方 `interactive_dialogue` 同时存在新版 `list` 包装和旧版顶层 `contents` 树。`_dialogue_trees()` 负责统一两种形态；更新解析时必须同时保留。该规则与任务对话缺失修复同样重要。

## 定向更新

```powershell
python src/modules/map_text.py --entry-id 506567 --force
python src/modules/map_text.py --repair-legacy
```

`--repair-legacy` 只用于将仍为旧标题文件名的地图文本按官方目录 ID 覆盖为稳定文件。完成后重建并校验 Manifest，再使用清理脚本处理确认重复的旧副本。
